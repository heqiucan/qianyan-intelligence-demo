## 新决定的最小记录

写 ID、日期、状态、来源、问题、备选方案、选择理由、受影响功能ID、代价、复核条件。取代旧决定时写 `supersedes: Dxxx`，旧记录标已取代并链接新决定，避免两条现行规则矛盾。暂不建立自动生成决策或自动记忆系统。

新增决定先写背景、备选、选择、影响和复核条件；没有用户确认的内容标为“提议”，不能写入“已确认”。
