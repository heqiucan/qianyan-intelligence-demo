# Qianyan Intelligence 产品操作手册

浙衍 AI Growth Studio 使用指南

版本日期：2026 年 11 月 17 日　适用代码版本：dc827fe

本手册用于在当前 Demo 中完成商品准备、内容审核、模拟投放、模拟购买和结果复盘。首次使用建议按第 2 至第 7 章完成一次直播电商流程；普通商品、医美内容和公网分享分别见第 8、第 9 和第 11 章。

系统会保存业务操作和版本记录。广告投放、付款与样例经营数据均为演示；页面显示的“已确认”表示你在本系统完成核对，不表示平台审核通过或真实开播。文中的商品名称、价格、预算和负责人均为练习示例，不是实际经营信息。

## 1 找到需要的功能

| 左侧入口 | 主要操作 | 常见下一步 |
| --- | --- | --- |
| 增长工作台 | 选择或新建活动，查看概况，启动 Agent | 准备商品或审阅内容 |
| 商品与品牌 | 原商品资料，商品目录与 SKU，知识库与 RAG | 建立货盘或生成草稿 |
| 营销与创意 | 活动创意，行业知识草稿，直播场次与货盘 | 确认素材并建计划 |
| 广告投放 | 创建与启动模拟计划，体验购买，载入样例 | 查看订单和效果 |
| 效果与获客 | 活动效果，直播场次复盘 | 保存复盘或报告 |
| 异常与待办 | 检查异常依据，记录处理情况 | 跟踪处理后的结果 |
| AI 优化复盘 | 生成复盘与调整草稿，建立观察 | 人工决定是否采用 |
| 活动报告 | 保存并查看活动报告和场次报告 | 导出或打印 |

**三个容易混淆的对象：** 营销活动组织一次推广；直播场次属于一个活动，保存本场货盘；投放计划绑定一份已确认素材，决定从哪个商品快照进入模拟购买。一个活动可以有多个场次、素材和计划。

**建议阅读顺序：** 打开系统 → 建活动和商品 → 确认货盘 → 准备并审核内容 → 确认素材 → 启动计划 → 模拟购买 → 按相同范围复盘。

## 2 打开系统并选择演示范围

### 本机启动

1. 打开项目文件夹，双击 `start-demo.cmd`，等待浏览器打开工作台。需要先展示官网时，双击 `start-website.cmd`。
2. 保持启动窗口打开。若系统已经运行，启动器会复用现有服务；再次双击不代表重启或加载了新后端代码。
3. 工作台地址为 `http://127.0.0.1:8000/#/overview`；官网为 `http://127.0.0.1:8000/website.html`。这些地址只供当前电脑访问。
4. 左侧出现八个功能入口、顶部出现活动选择框后，即可开始操作。停止本次启动的服务可在其启动窗口按 Ctrl+C，已保存的业务数据仍保留。

如果双击没有成功，在项目文件夹的 PowerShell 中运行以下检查，再查看提示处理依赖或构建问题：

```powershell
.\.venv\Scripts\python.exe scripts/start_demo.py --check
.\.venv\Scripts\python.exe scripts/start_demo.py
```

### 先看样例还是自己操作

首次介绍产品时，点击顶部“进入演示模式”。首页显示“历史 D0 · 虚构样例”，适合解释指标和流程。点击“返回工作模式”恢复之前的选择。切换模式不会自动生成订单或调用模型；有未保存输入时，先保存再切换。

要查看自己刚才的购买，进入“效果与获客 → 活动效果”，把“数据来源”设为“现场互动记录”，或点击“看我刚才的购买”。新建活动没有历史 D0 是正常情况。

### 没有资料时的快速体验

在“增长工作台”点击“从任务开始”，选择“直播电商”或“医美营销”，点击“开始内容任务”。“使用哪些资料”可选“预置虚构示例 · 可以直接体验”，填写任务后点击“开始任务”。这条路线适合先学习检索、引用和审阅；要完整演示指定 SKU 成交，请按后续章节从货盘启动。

### 看清内容来源

页面会标明当前是模型模式还是本地回放。回放仍会执行检索与保存流程，但正文来自有限规则或摘录。当前模型设置可在左下角“演示设置”查看；“测试免费模型连接”会实际请求模型，日常查看页面无需点击。

## 3 建立活动并录入直播商品

### 先选对营销活动

在“增长工作台”通过“选择营销活动”选择已有活动，或点击“新建营销活动”。填写必填的“活动名称”“活动开始日期”“活动结束日期”，按需填写“内部观察目标”“受众假设”“主推卖点”“预算上限”，点击“创建并开始策划”。练习时可命名为“直播操作练习”。保存后自动进入创意页，再进入“商品与品牌”准备直播商品。

活动是后续场次和计划的归属。开始新一轮练习时，新建活动比覆盖已有活动更容易核对结果。

### 添加商品和规格

入口：“商品与品牌 → 商品目录与 SKU → 新增直播商品”。

1. 填写“商品名称”“商品品牌”“已知商品事实”“商品资料来源”，检查“宣传限制”。测试资料必须写明“虚构演示设定”。
2. 在“规格 1”填写必填的 SKU 名称、价格、容量或规格、颜色、价格依据。默认价格为 99 元，须主动改为有依据的价格。SKU 是一个可单独定价的具体规格。
3. 需要多个规格时点击“增加 SKU”。每个 SKU 的价格和来源分别填写；“参考库存”可留空，填写库存后必须补充库存来源。
4. 点击“保存商品与规格”。成功后目录中出现商品卡片、版本号及 SKU 信息。失败时输入保留，查看页面错误后修正。

### 可照填的虚构练习资料

| 字段 | 示例内容 |
| --- | --- |
| 商品名称及品牌 | 演示随行杯；青禾演示品牌 |
| 已知商品事实 | 提供 350 mL 与 500 mL 两种规格；仅用于流程练习 |
| 商品资料来源 | 本手册虚构练习设定，不对应真实商品 |
| SKU 1 | 350 mL 白色；价格 59 元；价格依据为虚构练习定价 |
| SKU 2 | 500 mL 黑色；价格 79 元；价格依据为虚构练习定价 |
| 宣传限制 | 不承诺保温时长、销量、评价或未提供的性能 |
| 参考库存 | 留空；不要把未知库存填写为 0 |

**编辑已有商品：** 点击“编辑商品与 SKU”。标有“原演示商品”的卡片通过“编辑原商品资料”进入原编辑页。新直播商品当前使用通用占位图，尚无每个新商品独立上传图片或视频的入口。

**完成标志：** 目录中能看到所需 SKU 和正确价格。下一步进入“营销与创意 → 直播场次与货盘”。

## 4 建立场次并确认货盘

1. 确认顶部选中目标活动，进入“营销与创意 → 直播场次与货盘”，点击“新建直播场次”。
2. 填写“直播场次名称”“主播或负责人”“预计开始时间”“预计结束时间”，按需填写“本场目标”。例如场次为“随行杯规格讲解练习”，负责人为“演示运营员”。结束时间须晚于开始时间。
3. 在“选择货盘商品与 SKU”中选一个规格，点击“加入货盘”。需要多个规格时重复添加；同一 SKU 不能重复加入同一货盘。
4. 为每个条目填写“讲解重点”；有“本场优惠说明”时必须填写“优惠依据”。练习可先不填优惠，避免把说明误当成已实现的折扣计算。
5. 使用“前移”“后移”调整讲解顺序；不需要的条目点击“移出本次货盘”。点击“保存场次与货盘”。
6. 保存后点击“核对并确认货盘”，逐项核对商品、SKU、价格和优惠来源，勾选核对声明，再点击“确认货盘”。

**完成标志：** 场次显示“货盘已确认”和版本号，货盘条目中的“让 Agent 准备本商品讲解”可以点击。场次排期只用于筹备，不会到点自动开播。

### 两条内容准备路线

| 想完成的事 | 从货盘条目点击 | 接下来去哪 |
| --- | --- | --- |
| 展示检索依据和人工审阅 | 让 Agent 准备本商品讲解 | 第 5 章 |
| 快速获得活动文案草稿 | 准备本商品创意 | 第 6 章核对素材 |

推荐先确认货盘，再选择任一路线。“准备本商品创意”虽可在待核对场次生成草稿，后续确认素材和启动仍需满足货盘状态及版本要求。

### 修改价格或货盘之后

商品目录改价不会自动更新旧货盘。若本场需要使用最新价格，点击“编辑本场货盘”，核对目录价格后重新保存，再确认新货盘版本；保存会重新取目录中的商品和 SKU 快照。

货盘更新后，新内容需要基于当前版本重新准备、确认和建计划。旧创意、订单和报告保留原快照，不能用旧版本绕过确认。已经运行的计划不会自动停止，需要在“广告投放”中人工暂停或结束。

“归档场次”用于结束本地筹备管理，会限制新增内容和新计划；它也不会替你停止已有运行计划。

## 5 用 Agent 准备讲解并转入创意

### 从指定 SKU 开始

1. 在已确认货盘的目标条目点击“让 Agent 准备本商品讲解”，系统进入“增长工作台”的 Agent 面板。
2. 检查关联活动、场次、货盘版本和 SKU。“使用哪些资料”保留“本场已确认货盘 · 当前商品资料”，避免把其他示例资料用于当前商品。
3. 在“希望 Agent 完成的任务”输入：请依据本场当前 SKU 的已知事实准备规格讲解，说明规格、颜色和价格；不添加保温时长、销量、评价或未提供的优惠；缺失信息请列为待核实。
4. 点击“开始任务”。查看“Agent 执行记录”和参考依据，了解实际检索与读取了哪些资料。资料不足时按提示补充，不用猜测值补齐。

### 审阅当前草稿

打开草稿中的引用原文，核对正文与商品事实、价格及限制是否一致。需要修改时编辑正文，点击“保存修订版本”；勾选逐段核对声明，点击“人工确认并保存”，再点击“标记任务完成”。

**必须按顺序：** 草稿保存 → 草稿人工确认 → 标记任务完成。仅看到“草稿已生成”还不能代替后两步。

服务中断后，从左侧历史打开任务，先“刷新任务”，再按状态选择“继续任务”或填写补充要求后“提交要求并继续”。继续可能调用模型；事实缺口应先去知识库补充并审核，不能只把新价格写进补充要求。取消不会删除已有历史记录。

### 转为活动创意

1. 在满足转入条件的直播知识草稿中点击“转为活动创意”，打开“核对并转为活动创意”。
2. 核对“转入目标活动”、商品、SKU 和货盘版本。从货盘启动的任务已有固定绑定，不能随意换成其他活动或商品。
3. 检查“转入创意标题”“转入广告正文”“转入行动文案”“转入视频脚本”，必要时整理长度与措辞。勾选目标商品及待确认状态的声明，点击“确认转入创意草稿”。同一版本已转入时，可“打开已转入素材”。
4. 成功后进入“营销与创意”的对应创意。它仍是待确认素材，继续第 6 章；转入不会发布内容或启动投放。

### 完成后又修改了草稿

任务已经完成，但当前草稿又产生新修订时，点击“重新打开审核”，重新审阅并确认当前版本，再“标记任务完成”。重新打开本身不会调用模型，原完成记录仍保留。若是引用失效或货盘版本变化，应按提示重新准备内容，不能只重复点击确认。

## 6 确认素材并完成一次模拟购买

### 核对活动素材

进入“营销与创意 → 活动创意”，找到刚生成或转入的素材。检查标题、正文、脚本、目标 SKU 和价格，点击“核对当前文案”并处理问题。修改后“保存为新版本”，再“确认当前素材”，在核对弹窗点击“确认通过素材”。

知识草稿确认与活动素材确认是独立动作。人工改写后的新句子不会自动获得逐句引用，仍需自行核对。

### 创建并启动计划

1. 进入“广告投放”，点击“创建投放计划”。若按钮不可用，先确认当前活动下至少有一份已确认素材。
2. 填写“计划名称”，在“已确认素材”中选中正确版本，填写“计划总预算”“开始日期”“结束日期”。练习预算可填 300 元，这是模拟配置，不是扣款。
3. 日期应覆盖模拟启动当天。点击“保存计划草稿”，计划列表出现草稿记录。
4. 点击该计划的“确认启动”，核对素材快照、预算和日期，阅读模拟执行说明，再点击“确认模拟启动”。日期校验以运行服务的主机当天为准。

**完成标志：** 计划状态显示模拟运行，出现“体验购买”。计划不会按预算自动花钱，也不会按日期自动调度。

### 进入消费者体验

点击运行计划的“体验购买”，在广告预览点击素材的行动按钮，通常为“查看商品详情”，也可能是自定义文字。商品页核对规格和单价，选择“购买数量”（1 至 20）和“选择虚构测试买家”，点击“核对订单 · 金额”，再次核对后点击“模拟付款并下单”。成功显示“模拟订单已保存”和订单编号，无真实扣款。

用第 3 章的 59 元 SKU 练习、数量为 2 且没有修改价格时，模拟金额应为 118 元。这个数值仅用于检查当前流程是否沿用正确 SKU 快照。

点击“查看订单来源”，进入“效果与获客”的活动效果，系统已选中该活动、计划和现场记录。查看本场汇总时，再切换“直播场次复盘”。

### 计划调整和结束

运行计划可以“暂停”，暂停后可按条件“恢复”；已结束计划不能直接恢复，应复制建立新草稿。预算与周期变更通过计划详情中的调整草稿核对后应用。更换素材时建立新计划，原运行计划继续使用原素材版本。

**不要混淆：** 场次确认不等于开播，素材确认不等于发布，计划模拟启动不等于真实广告上线，模拟付款不等于真实交易。

## 7 找到成交结果并保存场次报告

### 查看自己刚才的订单

1. 在顶部选择购买所对应的营销活动，进入“效果与获客 → 活动效果”。
2. 展开“当前统计范围”，将“数据来源”设为“现场互动记录”，先“清除筛选”，再按需选择计划和日期。
3. 查看订单明细、金额和来源链路。刚才的订单不在“历史演示 D0”或其他独立批次中。

### 按直播场次复盘

1. 进入“效果与获客 → 直播场次复盘”，选择目标场次；也可在货盘页点击“查看本场结果”。
2. 检查本场商品、SKU、订单和成交来源。只统计明确关联本场的记录，D0 不会计入某场直播。
3. 选择现场记录或属于本场的独立模拟批次，查看对应指标和趋势；不要把不同来源的数字相加后解释为真实经营表现。
4. 可点击“生成本场复盘”，阅读结果与缺失信息，再“带入报告草稿”，修订“本场报告结论”和“本场下一步行动”；也可直接手动填写，无需先生成。
5. 点击“保存本场报告快照”，再“查看活动报告”，展开已保存场次报告，使用“导出场次报告 Markdown”保留文件。该入口当前不直接导出 PDF。

### 三类数据如何选择

| 数据来源 | 包含什么 | 适合看什么 |
| --- | --- | --- |
| 现场互动记录 | 本系统保存的测试点击、浏览和模拟订单 | 自己刚才的操作及订单来源 |
| 历史演示 D0 | 初始演示活动的固定虚构历史样例 | 讲解完整指标，不用于本场成交 |
| 模拟场景批次 | 人工预览并确认载入的固定场景 | 对比指定模拟情境与配置 |

**没有 ROI 是正常情况：** 现场记录没有对应真实广告消耗，因此消耗与 ROI 显示不可计算。计划预算不是已发生消耗，不能拿它代填。ROI 也不是利润。

**趋势如何理解：** 现场订单按实际 UTC 日期汇总；场次时间在表单按本机时区录入和显示，两者跨午夜时可能出现日期差异。只有一天记录时只有一个数据点；D0 和只有汇总数据的批次显示计划对比，不代表逐日趋势。

**报告为什么不会随数据变化：** 保存的是当时的数据来源、指标和版本快照。后续改价或新增订单不会静默改写旧报告，需要时保存新报告。

## 8 使用原商品活动流程

已有原商品流程继续可用。只推广原商品、暂时不需要直播场次时，可以按本章完成。

### 准备原商品资料

进入“商品与品牌 → 商品资料”，编辑商品名称、规格、价格、事实依据和宣传限制，点击“核对并保存商品资料”，检查差异，再“确认保存商品资料”。该页支持 PNG、JPG、WebP 图片和 MP4、WebM 已有视频，单文件最大 20 MB；上传后仍需保存资料。

旧活动继续保留创建时的商品资料快照。需要用最新原商品资料发起新一轮推广，可点击“使用最新资料新建活动”。不要认为改了商品页面，就已同步修改所有历史活动和订单。

### 建活动并生成创意

1. 在“增长工作台”新建营销活动，填写目标、受众、卖点和周期。
2. 进入“营销与创意 → 活动创意”，选择“表达语气”“表达角度”和“文案结构”，点击“生成两组创意”。
3. 当前是回放模式时，规格讲解、问答、演示步骤等为有限文案结构；相同内容可能复用已有素材，历史重复项默认折叠，可展开查看。
4. 打开一份素材，查看正文与脚本，运行事实核对，检查每条问题的依据和建议。
5. 采用建议后检查编辑框中的新文字，“保存为新版本”，再“确认当前素材 → 确认通过素材”。建议进入编辑框不等于已经保存。“预览 / 导出”中的“导出 PNG 海报”使用已保存版本。

### 投放与复盘

沿用第 6 章创建计划、确认模拟启动并体验购买，再按第 7 章用“现场互动记录”查订单。普通活动未绑定直播场次，其订单不会自动归入某一场直播。

需要带消耗的完整投放样例时，在“广告投放”打开模拟场景，选择运行计划和预设场景，点击“预览场景数据”；核对后“确认载入独立批次”。系统切换到对应批次的统计范围，现场订单仍单独保存。

### 演示时的两个核对点

**价格以当前快照为准。** 原初始化示例曾使用 99 元商品，不代表所有普通活动或直播 SKU 都应为 99 元。查看素材、计划和订单中的实际商品快照。

**编辑会产生新版本。** 素材修订后，旧计划仍用旧素材；要体验新文案或新价格，应确认新素材并建立对应新计划。

## 9 准备知识库并生成医美内容

### 导入并审核资料

入口：“商品与品牌 → 知识库与 RAG”。RAG 在这里指生成前先检索资料，再展示可查看的原文引用。

1. “业务场景”选择“医美获客”或“直播电商”，选择“机构 / 品牌资料空间”。没有空间时“新建资料空间 → 创建空间”；练习可“载入本场景示例”。
2. 点击“导入资料”，用“选择 TXT / MD / PDF”上传，或直接粘贴。限制为单文件 5 MB、50 页、12 万字以内。扫描图片型 PDF 没有 OCR，应先整理为可复制文字。
3. 填写“资料标题”“资料类型”“适用范围”、有效日期及正文，核对解析预览；有效期按 UTC 判断，日期可留空。
4. “保存资料，进入审核”后，点击“查看资料与审核”，核对内容、类型、范围与有效期，勾选声明，再“确认资料可用”。过期、归档或范围不匹配的资料不会作为有效依据。

历史脚本可帮助理解表达结构，但不能单独作为价格、资质、性能或机构事实的依据。

### 检索和生成草稿

点击“开始检索”进入“检索与生成”，在“输入关键词或任务”填写“咨询预约流程和审核要求”等原文关键词，选择范围和用途，点击“检索资料”。核对命中段落与“查看引用原文”，再点击“整理依据草稿（回放）”或“基于依据生成草稿”。后者会把任务和命中片段发送给已配置模型。

当前采用关键词检索。没有结果时，先检查资料是否可用、是否过期、场景和渠道是否匹配，再尝试原文中的具体词；不要直接将“没有命中”解释为“系统已确认没有该事实”。

### 医美内部 FAQ 路线

也可在“增长工作台 → 从任务开始”选择“医美营销 → 开始内容任务”。使用虚构示例或已审核的机构知识库，输入“根据现有预约流程整理内部 FAQ，未提供的信息列为待核实”，点击“开始任务”。

在“营销与创意 → 行业知识草稿”查看内容，核对引用，修改后“保存修订版本”，勾选声明并“人工确认并保存”。“导出草稿与引用”下载 Markdown。由 Agent 生成时，还需在任务中“标记任务完成”。

**本路线到内容确认与导出结束。** 医美 FAQ 不能转入商品成交计划，系统也没有咨询线索、预约和到店台账。人工确认代表内部审阅，不代表医疗广告审批。

**资料变更后：** 旧草稿保留当时的引用快照；资料失效会提示重新核对。有引用不代表每一句新增改写都已被验证。

## 10 处理异常并形成下一轮建议

### 异常与待办

进入“异常与待办”，核对活动，选择“检查数据批次”（只检查业务待办或指定模拟批次），检查“无成交消耗阈值 / 元”，点击“检查当前活动”。打开“查看与处理”，查看依据，选择“处理状态”，填写“处理备注 / 复查理由”，点击“保存处理记录”。已解决或已忽略必须填写理由。

完成标志是待办状态及处理记录已保存。把待办标为完成不会自动调整计划或补充缺失数据；需要暂停计划时，应到“广告投放”执行对应操作。

### AI 优化复盘

1. 确认活动、数据来源、计划、日期或批次的范围，再进入“AI 优化复盘”。也可在效果页点击“基于当前范围进行复盘”。
2. 点击“生成本轮复盘”，核对已知事实、待验证原因和建议。数据不足时先补充演示操作或选择明确的样例范围。
3. 选择“生成下一版素材”或“创建计划调整草稿”，点击“核对并创建草稿 → 确认创建草稿”。一条建议只采纳一种动作。再“查看并确认素材”或“查看并确认计划调整”，完成对应人工确认；不采用可“暂不采纳”并保存理由。
4. 在“观察任务”选择对应计划，满足执行条件后“开始观察”，后续“检查后续数据”。基线、计划、配置和来源须匹配；批次观察需使用开始观察后载入的新批次。

观察尚未覆盖对应时间窗口时，不能提前认定效果改善。对比结果只说明所选记录的差异，不证明真实广告因果效果。

### 保存活动报告

进入“活动报告”，核对当前范围，在“生成一份活动报告”填写必填的“报告标题”，按需填写“运营结论（人工判断）”和“下一步行动”，点击“保存新的报告快照”。打开历史报告，点击“打印 / 另存 PDF”，在浏览器打印窗口选择另存 PDF。

| 报告类型 | 从哪里形成 | 当前保存与导出方式 |
| --- | --- | --- |
| 活动报告 | 选定活动与数据范围后保存 | 历史快照，打印或另存 PDF |
| 场次报告 | 直播场次复盘页保存 | 场次快照，导出 Markdown |

活动报告与场次报告都在“活动报告”模块中查看，但覆盖范围和导出按钮不同。导出前检查标题、活动或场次、来源及时间窗口，避免把演示样例当作实际经营报表。

## 11 分享给他人并保留数据

### 创建免访问码的临时分享

以下操作在项目根目录的 PowerShell 执行。它会启动独立演示服务，使用独立分享数据和回放模式，不加载本机模型密钥。访客共用这个演示空间，之前的分享操作可能仍保留。

先检查已有分享；需要更换网址时，先停止旧分享并确认对应进程已经退出，避免重复启动。

```powershell
.\.venv\Scripts\python.exe scripts/share_demo.py status
.\.venv\Scripts\python.exe scripts/share_demo.py stop
```

在第一个窗口启动并保持窗口打开：

```powershell
.\.venv\Scripts\python.exe scripts/share_demo.py serve --no-access-code
```

另开第二个 PowerShell 窗口，同样进入项目根目录，读取本次网址：

```powershell
.\.venv\Scripts\python.exe scripts/share_demo.py status
```

把输出中的 `website_url` 用于官网展示，`workspace_url` 用于直接体验工作台。复制后先用浏览器实际打开，再发给他人；不要沿用旧文档里的历史网址。

演示结束后，在第二个窗口运行 `stop` 命令，或双击 `stop-share.cmd`。电脑须保持开机、联网且不休眠；停止或关机后网址失效，重新创建通常会更换网址。

**当前脚本的使用限制：** `status` 读取的是状态文件，不是实时在线检测；出现 `running` 或输出了网址，也可能尚不可访问。`serve` 窗口不实时打印网址，`分享信息.txt` 也不自动更新。`stop` 等待后未确认退出时，先检查原窗口或请求排查，不要反复启动或盲目结束旧 PID。

### 日常数据与备份

默认本机数据在 `data/`，包含业务数据库和上传文件。停止日常服务后再备份整个目录。不要删除数据库来恢复样例；新练习优先新建活动，独立验收应使用单独数据目录。

代码仓库不包含本机 `.env`、业务数据库、依赖目录和分享运行数据。GitHub 上保存源码，不等于恢复了这些本机数据，也不等于网站已经长期部署。

## 12 常见问题与演示检查

### 页面打不开

先双击 `start-demo.cmd` 并查看启动窗口错误。运行 `start_demo.py --check` 只能检查准备情况，不能证明整条业务流程可用。端口被其他程序占用时，排查后可使用 `--port 8001`，浏览器地址也相应改为 8001。

### 找不到刚才创建的场次或订单

先核对活动选择。场次只在所属活动内展示；自己的模拟订单选择“现场互动记录”，清除计划和日期筛选。场次复盘还需检查订单是否由本场货盘关联的素材与计划产生。

### Agent 无法转为活动创意

检查是否为直播内容、当前草稿是否已人工确认、Agent 是否完成了当前草稿版本、引用是否仍可用、目标活动和货盘是否匹配。完成后又改过草稿时，重新打开审核；医美 FAQ 不支持转入。

### 无法确认素材或启动计划

核对当前商品事实、引用状态和货盘版本。货盘变更后重新保存并确认，再准备新内容；计划周期必须覆盖启动或恢复当天。不能通过反复点击确认跳过版本校验。

### 改价后购买仍显示旧价格

旧计划使用创建时的素材和商品快照，这是预期行为。要使用新价，确认新货盘和新素材，并创建新计划；旧订单和报告继续保留原价。

### 文案重复或模型执行失败

回放模式可能复用同文素材，尝试不同文案结构或展开历史记录。真实模型报错时先查看任务提示，确认当前配置、资料和限制，再手动重试；不要为继续演示自行切换付费型号。公网分享固定回放，输出与本机模型模式可能不同。

### 向他人演示前逐项检查

- 当前处于预期活动；演示 D0、现场操作和独立批次的来源讲清楚。
- 商品、SKU、价格来源齐全；货盘已确认，使用的是目标版本。
- 草稿已审阅并完成任务；活动素材另行确认；计划已人工模拟启动。
- 亲自完成一次模拟购买，并能在正确范围找到该订单。
- 场次或活动报告已保存，知道对应的导出方式。
- 若使用公网链接，已在浏览器实际打开；分享窗口保持运行。

本版本未接入真实开播、广告账户、真实支付、库存自动扣减、退款利润核算、多店租户及生产级账号权限。演示应围绕已实现的内容准备、人工审核、模拟成交和版本追溯展开。
