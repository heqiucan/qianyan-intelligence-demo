# Qianyan Intelligence 官网实施与验收

日期：2026-11-10。交付范围：独立产品官网、本地可交互演示、既有工作台入口连接。

## 访问与启动

- 官网：http://127.0.0.1:8000/website.html
- 工作台：http://127.0.0.1:8000
- 启动官网：项目根目录 `start-website.cmd`。
- 原 `start-demo.cmd` 仍打开工作台；工作台顶部“产品官网”在新标签页打开官网。
- 官网各模块入口与“进入工作台”使用同源链接，可以随现有服务一起部署。2026-11-11 已新增临时公网分享，详见 `docs/临时公网分享说明.md`；未配置长期云端托管。

## 已实现内容

1. **品牌首屏**：Qianyan Intelligence 完整名称、黑紫色、独立品牌图形、粒子环、流动光带、移动鼠标的轻微视差。
2. **背景控制**：轨道、流动、聚合三种形态；暂停和继续。系统开启减少动态效果时保持静态，形态仍可切换。
3. **页面导航**：固定顶部导航、桌面章节指示、手机折叠菜单、回到顶部、跳过首屏链接。
4. **六步流程**：商品资料 → AI 创意 → 内容核对 → 广告投流 → 成交追踪 → 优化复盘。支持点击、方向键、Home/End 切换。
5. **流程内交互**：切换创意角度、核对三处示例文案问题、查看修订与原文、调整预算并计算七天预算、查看订单关联、展开优化草稿。
6. **八大模块**：增长工作台、商品与品牌、营销与创意、广告投放、效果与获客、异常与待办、AI 优化复盘、活动报告。每个模块都能进入既有 Demo 对应页面。
7. **产品设计重点**：商品事实依据、版本关联追踪、数据来源区分、建议到草稿的衔接。没有将它们包装成行业独有能力或已经验证的经营提升。
8. **常见问题与体验入口**：解释官网与工作台关系、模拟边界、AI 参与位置，以及多平台和直播的后续范围。

## 内容与数据边界

官网中的商品、创意、预算、订单路径和优化建议都是固定讲解示例，页面明确标注“交互示例”“案例示意”。按钮仅更新本页状态，不向业务 API 写入，不调用智谱接口，不改变现有商品、活动、创意、计划或订单。

已有工作台继续支持配置智谱模型。官网使用“支持接入”等能力表述，不动态宣称当前密钥在线或模型已经生成了本页文案。投放执行、付款、预算均明确为模拟。没有真实平台归因、真实多平台账户、真实直播或自动花费的宣传。

## 实现组织

- `frontend/website.html`：独立 HTML 入口，包含页面标题、描述和禁用 JavaScript 时的说明。
- `frontend/src/website/Website.tsx`：页面结构、章节跟随、手机导航。
- `frontend/src/website/JourneyPreview.tsx`：流程切换及各步骤的交互示例。
- `frontend/src/website/content.ts`：功能、流程和常见问题文案。
- `frontend/src/website/particleEngine.ts`：原创 Canvas 粒子、光带、视差和生命周期管理。
- `frontend/src/website/ParticleField.tsx`：React 与画布的连接及清理。
- `frontend/src/website/website.css`：独立样式与响应式规则，不加载到业务工作台。
- `frontend/vite.config.ts`：两个 HTML 入口共同构建，保留既有 React 19.3.1 / Vite 8.3.6 / TypeScript 7.0.2 / Lucide 1.70.0；无新增运行依赖。
- `scripts/start_demo.py`：新增 `--page website`，默认仍为工作台；不改变数据目录或模型设置逻辑。

粒子引擎将绘制频率目标限制在每秒 30 帧，窄屏降低粒子数，像素比上限 1.5；离开首屏、切到后台或手动暂停时停止动画循环，卸载时清理监听器和观察器。这些是实现策略，不是对所有设备帧率的保证。
