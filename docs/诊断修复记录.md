# 浙衍 AI Demo 诊断修复记录

日期：2026-11-17。范围为现有单机 Demo 的需求到内容流程、规则核对、运行恢复及可重复交付。保留现有八菜单、主题、历史快照和真实模型配置。

## 已实现的行为

1. **旧资料逐条导入**：从原始页和行拆分编号词条，显示预览、标题排除、重复标记、版本、来源行；不把 600 字检索片段当成词条。可以显式更改用途，建立需求素材待审核新版本并保留旧版。归档资料也可复制为独立需求副本。
2. **词库资产**：每词保留角色、人工状态、来源、标签、别名、历史版本；已确认结果可回存词库。每一类筛选词最多 30 条，完整素材仍保留在批次，不隐藏截断。
3. **分组内容**：人工同组需求汇成一个主题，保留所有成员；多层交接递归使用原始问题。FAQ 逐问显示原文依据和引用；每次最多 12 问、每问 500 字，超限要求拆组。选句后再次检查价格、地址等必要依据；咨询免费不能替代项目报价。部分回答缺依据会留缺口并阻止整组确认。
4. **编辑与恢复**：过时 plan/preview 不覆盖新输入；选中任务、空间和步骤保留在 URL；完整审核历史支持按操作撤销；补事实可返回原任务；空空间有入口。CSV 和 Markdown 保留来源。
5. **文案依据**：物流和性能时长分别核对。商品页可维护人工确认的结构化原文、来源和适用条件；同类别完整子句匹配后才能支持对应主张。自由文本和保证性表述不获得自动放行，旧活动继续使用旧商品快照。
6. **模型可见性**：侧栏与设置显示正在占用的任务类型、开始时间、历史接口成功及最近调用记录。记录持久化并区分回放、真实请求、失败和中断；重启不自动重发。只保存脱敏元数据和接口实际 token 用量，不保存提示词、资料正文、输出或密钥；费用未知时不估算。
7. **请求恢复**：请求有超时、取消等待、非 JSON 与网络错误提示；结果不明确时，相同操作重试沿用请求标识。页面级 ErrorBoundary 提供恢复入口。任务轮询隐藏暂停、稳定任务降频、错误退避，同一页面不并发轮询。
8. **数据和交付**：只读事务不再抢 SQLite 写者位置；新增空间/任务索引与版本迁移表；任务列表不读完整结果。数据目录使用进程租约，阻止重复实例共享同库。新增固定开发依赖、随机端口临时库 E2E、CI、在线备份校验与恢复到新目录工具。计划日期与统计统一按 UTC，页面说明边界。
9. **访问默认值**：Host 白名单、基本内容安全策略；有访问码时 API 文档也受保护。公网分享模式关闭 API 文档，继续独立回放库；无访问码分享需要额外明确参数。正常局域网启动要求访问码与主机白名单。

## 保留的边界

- 仍为单用户本地 Demo；没有账号/RBAC、真实广告投放、支付或 CRM，同一模型请求仍串行。展示占用和失败原因，不虚构剩余时间。
- 引用存在不等于全文语义已被证明。需求内容采用原文选句，通用知识生成及人工改写仍需逐段核对；未引入自动事实判定器。
- 本轮没有全量改成关系型业务表、全接口分页、自动删除请求记录或文档历史；保留幂等与旧引用。SQLite 日志模式未强制改 WAL，避免只改参数而忽略部署/备份约束。
- 对外演示继续使用公开测试素材；访问码不是多用户权限系统，上传静态地址仍需按公开素材处理。Docker 和长期云部署未在本轮完成验收。
- 同义词范围、价格对象和医疗边界仍是规则辅助，不是对全部自然语言表达的语义证明；无法核实的内容必须补依据或人工调整。

## 上游参考与本地适配

- [Playwright 1.62.1](https://github.com/microsoft/playwright/releases/tag/v1.62.1)，Apache-2.0：使用其浏览器自动化及固定依赖；隔离库、流程断言、错误注入和来源核对为本项目实现。
- [CPython 3.12 sqlite3](https://github.com/python/cpython/blob/3.12/Lib/sqlite3/dbapi2.py)，PSF：按连接生命周期与在线 backup 接口处理一致备份；目录限制、清单、哈希及恢复策略为本项目实现。[SQLite WAL 文档](https://www.sqlite.org/wal.html)用于核对并发与部署约束。
- [React Error Boundary](https://react.dev/reference/react/Component#catching-rendering-errors-with-an-error-boundary)，沿用项目 React 19.3.1 / MIT：页面恢复组件按本项目编写。
- [Starlette TrustedHostMiddleware](https://github.com/Kludex/starlette/blob/main/starlette/middleware/trustedhost.py)，BSD-3-Clause：沿用 FastAPI 当前安装版本的中间件，增加符合本地、局域网与临时分享场景的白名单。
- Motion MCP 本会话未加载，实际读取本地固定上游的 product-ui 参数并运行 validator；未更换框架。商品视频保留 controls，不为背景视频规则强行自动播放。静态检查和浏览器业务验收分别记录。
