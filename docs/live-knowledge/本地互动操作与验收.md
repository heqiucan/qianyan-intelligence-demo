# 本地互动操作与验收

## 已实现

1. 当前场次 → 自动互动规则 → 导入 Markdown 模拟规则。
2. 选择当前讲解商品，逐条检查关键词、模板、来源、有效期与回复方式，勾选人工确认。
3. 开启本场自动互动并恢复规则响应；保存后仅新事件生效。
4. 启动本地模拟，在本地互动模拟输入问价弹幕，或模拟进场、关注。
5. 评论区查看回复、冷却、未匹配、过期、缺少依据和人工接管结果。
6. 语音/文字与语音规则还需保存主播助播音色，在当前话术区勾选“允许本页自动播报新互动”。刷新关闭许可，历史事件不重放。
7. 点击立即人工接管：当前浏览器暂停语音并关闭自动语音许可，服务端使旧互动语音队列失效。其他浏览器正在播放的当前音频不能远程撤回，会在下一片段或继续时阻止旧队列。

## 变量

支持 {商品名称}、{商品价格}、{商品规格}、{观众昵称}。商品字段只从所选的已确认货盘取值。手动话术队列通过“话术变量商品”选择来源，展开后的内容与商品引用保存在队列快照。没有所需字段或未知变量则阻止生成，不猜测。

每个新互动检查规则确认、有效期、商品版本与全局屏蔽词。规则按列表顺序首条命中，关键词为规范化后的包含匹配，不是向量检索或大模型问答。多问题弹幕目前不会拆成多个问答。

## 模拟资料

规则源文件：[[rules/模拟互动规则]]。索引：[[INDEX]]。使用 Obsidian 打开 docs/live-knowledge 文件夹即可查看；当前没有自动连接用户已有私人库，也没有安装插件。

样例中的30秒冷却与昵称降级是测试默认值，不是法律要求。商品价格来自演示货盘而不是写死在规则。发货、运费、售后没有真实资料，样例只提示人工核对。模拟样例默认未确认且自动互动关闭。

连续进场/关注目前采用规则级冷却抑制，不做人数统计和延迟聚合文案。昵称仅允许1–12个中英文字母或数字，其他内容或命中屏蔽词则降为“这位朋友”。

## 范围

已实现：关键词文字回复、关键词语音队列、进场欢迎、关注感谢、人工接管、规则版本、有效期、去重冷却、商品变量、屏蔽词、结果记录和 Markdown 导入。

未实现：真实抖音公屏、弹幕接口、向量 FAQ 问答、生成式智能客服、定时报时、规则优先级拖拽、多人关注聚合计数、AI 自动改写、完整法规标识校验。UI 上的客服入口用于本地规则与人工接管，不宣称已有生成式客服。

语音在当前页面显式允许后加入队列；暂停主队列时不强行恢复。每页队列积压最多50片段，超出提示人工处理。事件重试沿用请求ID，不重复创建结果和语音快照。
