# 工作台深浅主题

> 对应功能 ID：THEME。当前开发入口见 [项目索引](INDEX.md)，影响范围和测试见 [功能责任矩阵](功能责任矩阵.md)、[测试地图](测试地图.md)。本文件保留主题实现细节。

工作台新增浅色主题，保留原深色布局。浅色参考用户提供的工作总览图片，采用白色内容表面、浅灰背景、淡紫选中项及语义色指标。没有使用全页面反色，不改变商品图片、视频、海报或录制内容。

## 使用

- 顶栏太阳/月亮按钮切换浅色或深色。
- 设置 → 外观可选择浅色、深色或跟随系统。
- 首次默认浅色；选择保存在当前浏览器，刷新后恢复。同源标签页会同步。
- 选择跟随系统时响应系统主题变化；显式选择浅/深色后不再跟随。
- 主题改变不刷新页面、不重新挂载业务组件，不调用业务写入或模型接口。
- 报告打印继续采用原白底打印样式，与屏幕主题分开。

## 代码

| 文件 | 职责 |
| --- | --- |
| `frontend/public/theme-init.js` | 页面首屏提前读取主题，避免等待 React 后才切色 |
| `frontend/src/app/theme.ts` | 主题状态、系统与跨标签监听、存储不可用时的内存回退 |
| `frontend/src/app/ThemeControls.tsx` | 顶栏图标控件与设置中的三项选择 |
| `frontend/src/app/theme.css` | 主题变量、应用外壳、基础控件与首页配色 |
| `frontend/src/app/theme-business.css` | Agent、需求、知识、创意、投放、直播、图表、报告的旧颜色适配 |
| `scripts/browser_theme.cjs` | 主题持久化、系统变化、草稿保护、视频播放和窄屏检查 |

继承现有 React 与 lucide，未新增依赖。参考项目固定 Motion Site Builder product-ui 参数及 CoastSignal 明暗语义色方式，主题同步和业务状态保护针对当前项目实现。

npm.cmd --prefix frontend exec -- tsc --noEmit -p frontend/tsconfig.json
