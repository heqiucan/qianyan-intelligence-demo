## 自动化业务验收

运行命令：

```powershell
.\.venv\Scripts\python.exe -m pytest backend/test_business.py -q --basetemp=.pytest-temp-delivery
```

结果：**14 passed，1 warning**。使用独立临时数据库，未写入默认 `data/`。

- 固定历史 D0 指标复核，以及现场订单与历史数据隔离。
- 无曝光和消耗时，CTR、ROI、获客成本等保持不可计算。
- 新买家重复购买、已知老买家、未知历史，以及支付买家去重。
- 同一请求并发提交只生成一个订单；同请求标识不同内容返回冲突。
- 点击事件幂等；暂停或结束计划不能接收新点击与订单。
- 修改商品或素材后，已有活动与计划快照保持不变。
- 价格、容量和指定禁止宣传表达冲突阻止确认。
- 未确认素材无法建立计划；预算、日期和状态受校验。
- 采纳复盘创建草稿，不自动创建投放或效果数据。
- 新活动不能冒领 D0 历史，复盘不能跨活动采纳素材。
- 关闭重开数据库后订单保留；共享访问码校验有效。
- 不支持的上传格式、伪装 PNG 和外部媒体地址被拒绝。

唯一警告来自当前 Starlette TestClient 对 httpx 的弃用提示：建议后续迁移到 httpx2。当前 14 项测试通过，未将该警告表述为产品运行失败。
