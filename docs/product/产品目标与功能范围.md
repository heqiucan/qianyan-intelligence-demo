# 产品目标与功能范围

状态：目标与实现现状分列。更新：2026-11-23；实现核对基线 `8b09a7a`。来源：本会话已确认的六项改进、主题与官网要求、直播交接。功能 ID 对应[责任矩阵](../功能责任矩阵.md)中的代码入口。

## 目标

浙衍 AI Growth Studio 要成为可持续使用的营销运营工作台，以 Agent 任务为重要特色，帮助运营者把商品事实、知识资料、需求分析、内容生产、投放、成交分析、复盘和直播工作衔接起来。

当前实现是本机单体应用，以单店/单运营员流程为基础。部分模块是可用本地工具，部分平台动作是模拟；这描述现状，不把“仅做 Demo”设为产品终点。未来是否多租户、云端部署、接哪些平台及商业计价方式尚需另行确认，不能从长期方向推导本批授权。

## 核心对象

- 商品与 SKU：事实、来源、规格、价格、版本。
- 知识空间和资料：机构/品牌范围、文档、片段、审核和引用快照。
- 营销活动：推广目标、商品快照、策略版本。
- Agent 任务：目标、执行事件、引用、草稿、人工确认和交接。
- 创意：内容版本、事实核对、审批、活动绑定。
- 投放计划：素材快照、预算周期、模拟运行和批次。
- 订单/消耗/效果：明确来源和统计窗口的模拟业务数据。
- 直播场次：场次、货盘、SKU快照、画面、互动、语音和本地媒体任务。
- 复盘/报告：分析快照、人工结论、观察任务和历史报告。

## 已确认的体验要求

- 一级领域稳定，二级列表与操作台、三级对象详情按任务分级；首页不堆完整编辑器。
- Agent 有独立任务入口，业务内仍能带上下文发起；现有内容任务和需求任务分别运行，不宣称已经统一执行引擎。
- 同一任务内部切换保持归属，返回和刷新有确定路径，保护未保存输入和媒体运行状态。
- 使用精简操作文案，保留事实来源、模拟/未接入、版本冲突等必要提示。
- 数据和任务过程可视化，缺失值不补造；图表能找到原始明细。
- 深浅主题与系统跟随共存，官网入口持续可达；切换视觉不改变业务数据。

## 当前功能及业务归属

| 能力 | 归属 | 当前实现/依赖 | 完成判断 |
| --- | --- | --- | --- |
| 页面框架与统计摘要 | SHELL / HOME | 已实现；指标来自所选活动/数据范围 | 功能可定位、旧链接兼容、待办能进入对象 |
| 商品、SKU与活动 | PRODUCT / CAMPAIGN | 已实现资料录入/版本/快照；无平台库存同步 | 价格依据可查，旧活动不被悄悄覆盖 |
| 资料与检索 | KNOWLEDGE | 已实现导入/审核/关键词检索；语义检索取决于本机模型 | 引用可定位，模型缺失时明确降级 |
| 内容任务与交接 | AGENT / HANDOFF | 已实现执行/补充/取消/审阅/完成；模型配置与回放分开 | 只从可用依据生成，确认版本满足转创意条件 |
| 需求分析与选题 | DEMAND | 已实现导入/筛选/确认/撤销/交接 | 需求来源与事实来源区分，状态冲突不会覆盖确认 |
| 创意制作 | CREATIVE | 已实现生成/修订/检查/审批/导出；模型效果依配置 | 来源、版本、审批可追踪 |
| 投放与购买 | ADS / CONSUMER | 模拟计划、批次、事件与订单，非真实投放/扣款 | 订单保留计划/素材/商品归属 |
| 效果、待办、复盘和报告 | ANALYTICS / FEEDBACK | 已实现范围计算、图表、待办处理、报告快照/打印 | 缺失值与0区分，结果可回查 |
| 直播准备与控制 | LIVE | 已实现场次/货盘与本地模拟运行 | 货盘确认独立于模拟启动，版本变化拦截旧配置 |
| 画面、音频和录音 | PREVIEW / AUDIO | 浏览器本地预览、五路音频、录音回放 | 文件/设备权限显式申请，切场次释放资源 |
| 话术与互动 | SPEECH / INTERACTION / SCRIPTS | 系统语音、规则回复、定时、本地草稿审核 | 不自动向平台发送，不重播旧事件 |
| 素材处理 | MEDIA | FFmpeg转换/静音切片、人工字幕；依赖本机工具 | 上传限制、取消、产物来源和字幕可验证 |
| 外观与官网 | THEME / SITE | 已实现浅/深/系统主题与独立官网 | 切换不丢状态，官网入口可打开 |
| 基础设施 | STORAGE / MODEL / OPS | SQLite、受控模型适配、启动/备份/分享脚本 | 保持数据隔离、幂等与明确调用来源 |

## 明确不应伪装成已完成

以下均为待接入或待验收候选，不是本轮开发承诺；选择新批次时先明确范围、成本、权限和验收依据。

- 抖音账号授权、真实弹幕/礼物/在线人数/GMV、公屏发送、正式推流。
- 真实广告账户、平台商品卡、自动补链接、真实支付和扣费。
- 向量/生成式客服的完整多轮运营；当前规则互动和内容 Agent 不是同一能力。
- 自动 ASR、语义切片、高质量本地 TTS、音色克隆、实时麦克风插话。
- OBS/虚拟声卡、合成视频导出、混音成品导出、商业美颜和平台去重。
- 真实算力计费、余额、卡密、退款、支付和完整法规认证。

## 设计优先级

1. 事实来源、版本和人工确认可追溯。
2. 高频工作有明确入口，页面按领域和对象分级。
3. Agent 执行状态可查，不能用虚构进度替代事件。
4. 数据图表可解释，缺失值和模拟边界清楚。
5. 本地任务和媒体资源可取消、恢复或释放。
6. 桌面和窄屏可用，浅色/深色主题不影响操作。

新增功能的最小条目：功能 ID、用户要完成的任务、主责模块、输入/输出、上游/下游、现状、目标、验收与外部依赖。先标候选，范围获确认后再实施；实现后同步真实代码入口。产品目标、实现和验证分别更新，不能以“按钮存在”作为完成证据。
