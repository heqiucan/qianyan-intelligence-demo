# 知识检索增强与验收

日期：2026-11-17。这是在现有 React / FastAPI / SQLite 项目内增加检索能力，没有迁移整个知识库框架。

## 操作变化

1. 进入「商品与品牌 → 知识库与 RAG」。导入资料后点「查看资料与审核」，核对正文、范围和有效期，勾选确认并点「确认资料可用」。
2. 进入「检索与生成」，输入问题。默认「混合检索（关键词 + 语义）」，也可选择「关键词检索（含同义词扩展）」。
3. 查看实际检索方式、检索词、同义词扩展、每个候选的原文和「关键词匹配 / 语义相关」标记。相似度不表示事实置信度。
4. 如果出现错字建议，只有点击建议按钮才替换对应词并重新检索；系统不会静默改写。建议不等于已确认用户本意。
5. 搜索最多展示 12 个片段。同一文件可以贡献超过 2 个片段；生成选取最多 6 个，优先事实/审核依据，并在同类依据间适度分散文件。界面用「用于生成」标明选取项。未选取的候选不能被模型冒用为引用。
6. 草稿仍须查看引用并人工确认。生成模型模式下，仅选取的片段与任务发送给原先配置的智谱接口；语义检索本身完全在本机运行。

模型缺失、依赖不可用或本地计算失败时，关键词检索仍可使用，页面说明具体的降级状态。第一次加载模型需要等待；后续会复用内存中的模型和文本向量。没有调用付费 embedding API。

## 实现与取舍

- 原来的 jieba 分词 + SQLite FTS5/BM25 保留；标题仍可参与关键词匹配。医美与直播各有可阅读的近义词小词表，不把项目、疗效或品牌当同义词互换。
- 新增 BGE 小型中文向量模型。以正文计算向量，与 BM25 按 Reciprocal Rank Fusion 排名合并（常数 60），不把 BM25 与余弦值直接相加。
- 原始 600 字片段、PDF 页码、版本与 ID 不变。向量内部使用 tokenizer 计数的重叠窗口，并对长片段补充句子窗口，覆盖末尾正文。来源引用始终保存原片段。
- 纠错使用 RapidFuzz 单字符编辑距离和明确错字规则。目标必须属于业务白名单且出现在当前可检索词表；不提供通用拼音纠错或医疗名词自动替换。
- 只把当前空间、渠道、已审核且有效的资料提供给语义排序。向量计算不持有 SQLite 写锁；返回搜索、生成前后和 Agent 写回时重新核对资料状态。模型加载、计算及缓存均在本机，禁止请求内下载与远程 Python 代码。
- 内存 LRU 缓存按内容哈希建键，最多 8192 个窗口向量；资料改版后正文变化会重新编码。旧草稿保存的原文不会被新向量或新版文档替换。
- 当前逐次扫描经过过滤的本机资料，并计算余弦分数。适用于本机小资料库；没有引入 Qdrant 或 ANN，尚未做十万级片段性能验收。

## 本地准备与配置

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt -r backend/requirements-semantic.txt
.\.venv\Scripts\python.exe -X utf8 scripts/setup_knowledge_embeddings.py
```

下载约 96 MB 模型权重以及少量配置、词表到 `.models/bge-small-zh-v1.5`。推理依赖还包含 PyTorch 等，安装体积高于权重大小。`.models/`、`.venv/`、业务数据和临时验收文件不进入 Git。

可选环境变量：`KB_SEMANTIC_ENABLED=0` 禁用语义模型；`KB_EMBEDDING_MODEL_PATH` 指定本地模型目录；`KB_SEMANTIC_MIN_SCORE` 控制余弦门槛。启动器只加载这些明确允许的配置项，不自动下载依赖。

默认采用正文向量、无查询指令前缀和 0.45 门槛。这来自当前固定虚构样本的小规模校准，不是通用准确率保证。原先拼接泛标题、加查询前缀与 0.55 门槛时，六条无共同关键词的正例均漏召回；逐项对照后才调整编码方式与门槛。BGE v1.5 [官方模型卡](https://huggingface.co/BAAI/bge-small-zh-v1.5)支持无指令用法。正式业务仍需拿真实问题、容易混淆的问题及无答案问题继续评估，不能把小样本结果外推为行业准确率。

## 可重复验证

所有自动验收使用隔离数据和 replay 生成，不修改用户日常资料，不调用真实生成接口。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest backend -q --basetemp=tmp/pytest-hybrid-full-20261117
npm.cmd --prefix frontend run build
.\.venv\Scripts\python.exe -X utf8 scripts/check_knowledge_retrieval.py
```

离线测试默认禁用真实向量模型，语义边界测试使用明确标注的替身。真实模型脚本单独启用本地已下载模型并设置 Hugging Face 离线模式；脚本会报告漏召回，不将缺失模型当作验收通过。

真实模型报告：`tmp/retrieval-acceptance/model-report.json`。浏览器验收使用独立 replay 服务 8034，脚本 `scripts/browser_knowledge_retrieval.cjs`，截图与报告保存在 `tmp/retrieval-acceptance/browser/`。
