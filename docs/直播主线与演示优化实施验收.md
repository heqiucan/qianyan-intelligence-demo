# 直播主线与演示优化实施验收

日期：2026-11-13。依据用户“先主直播”及“再加上优化我给你的建议，开始吧”的授权实施。本文更新旧交接中的单商品边界，只记录已实现与实际验证的行为。

## 可直接体验的路线

1. 打开本机工作台 `http://127.0.0.1:8000`。首次讲解可点顶部“进入演示模式”：明确展示“历史 D0 · 虚构样例”，退出恢复此前所选范围。进入模式不会创建订单、切换模型或改写资料。
2. 在首页选择或创建营销活动。到“商品与品牌 → 商品目录与 SKU”添加商品及规格，填写各 SKU 价格和依据；录入库存时须同时填写来源。用户现有商品仍可用于货盘，原商品编辑入口继续保留，不恢复成初始化示例商品。
3. 到“营销与创意 → 直播场次与货盘”新建场次，填写负责人和时间，选择商品与 SKU，调整讲解顺序。保存后是待确认状态，核对价格、优惠依据后人工确认货盘。
4. 从某条货盘点“让 Agent 准备本商品讲解”。任务绑定该场次、货盘版本及 SKU，不会套用普通活动的 99 元默认商品。审阅草稿、人工确认、完成任务后，转成待确认的活动创意。
5. 确认素材，沿用“广告投放”建立并人工启动模拟计划；从计划打开消费者演示并完成模拟购买。付款不扣款，价格按创意内保留的 SKU 快照计算。
6. 到“效果与获客 → 直播场次复盘”查看所选场次的订单、SKU、成交来源和走势，生成复盘草稿并保存报告；“活动报告”可以查看与导出场次快照。

也可从货盘直接生成活动文案。Agent 路线适合演示带依据的审阅过程，直接生成适合快速准备商品素材。

## 本轮完成内容

| 模块 | 实际行为 |
|---|---|
| 单店商品目录 | 多商品、多 SKU，各自价格、规格和来源；编辑采用版本校验，原商品只读投影，不迁移覆盖 |
| 直播筹备场次 | 绑定一个营销活动，负责人、排期、目标、货盘顺序、优惠说明、人工确认、归档和历史版本 |
| 内容绑定 | 场次、版本、货盘条目、商品和 SKU 贯穿任务、知识草稿、创意、计划、事件、订单与报告 |
| Agent 再次审核 | 已完成任务的草稿修订后，可重新打开审阅、再次人工完成；保留此前完成记录，不为重新完成而调用模型 |
| 场次复盘 | 仅统计明确属于本场的计划与订单；独立模拟批次需属于本场；不接收无场次归属的 D0 |
| 不可变报告 | 保存数据来源、指标和货盘快照；导出同时列出成交实际使用的货盘版本，避免混淆最新版与旧订单 |
| 数据保护 | 商品或货盘改价不回写既有创意和订单；过期货盘不能再次确认素材、创建或恢复计划；正在运行的模拟计划仍使用原快照，需人工暂停 |

## 验证记录

自动业务验收全部使用 `tmp/` 下的独立数据和 `replay` 模式，不使用本机原数据做测试订单，不调用真实模型。本机原配置仍为智谱免费模型 `glm-4-flash-250414`；本轮没有再次执行真实模型端到端生成，因此不把回放通过当成新的模型连通性证明。

- 后端完整回归：**226 passed，1 个已有的 Starlette/httpx 弃用提示**。其中直播新增 25 项，覆盖多规格计价、来源与归属隔离、幂等提交、乐观版本校验、旧快照、归档、任务再审核、回放去重及不伪造时间序列。
- 前端：TypeScript 检查和 Vite 生产构建通过，无新增运行依赖。
- 新直播浏览器流程：**28 项通过**，覆盖表单错误保留输入、排序、确认、Agent、修订再审核、正确 SKU 转入、模拟订单、报告导出、回放去重、窄屏和减少动画设置。
- 原使用引导与创意转入流程：**28 项通过**，验证原路线可继续使用。
- 更新后的本机 8000 服务：**8 项只读检查通过**，覆盖原商品进入新货盘、演示模式切换、各新增入口与空状态、独立官网；没有业务写入和脚本异常。证据在 `tmp/live-acceptance/local-service/result.json`。
- 浏览器实测 1440 px、1366×768 和 390 px；检查的首页、目录、货盘、复盘及场次弹窗无页面横向溢出；新流程无浏览器脚本异常。另通过隔离响应验证不连续日期的横坐标按实际日数间隔排列，而非平均分布。
- 实际调用 Motion MCP 的 `product-ui` 参数、参考检索及文件检查；最终相关文件得分 98–100，0 error / 0 warning，部分有通用 ARIA / 按钮反馈 info 提示。实际按钮、表单与图表检查以上述浏览器结果为准。

## 仍未实现或有限的能力

- 这是单店直播**筹备与模拟成交**。没有接入真实开播、平台在线人数、观看时长、直播成交归因、抖音广告账户或真实支付。
- 库存是带来源的人工参考值，不同步平台、不自动扣减、不做库存预占。优惠字段保存说明与依据，模拟结算仍用 SKU 价格，不执行优惠叠加规则。
- 新增直播商品目前以文字事实和 SKU 为主，图片使用明确标注的通用占位图；每个新增商品独立上传图片 / 视频的管理入口尚未提供，原商品媒体入口继续保留。
- 未实现退款售后、成本利润、完整 CRM、多店多租户权限或直播排期自动调度。场次“已确认 / 已归档”不表示平台“正在直播 / 已结束”。
- 现场缺少广告消耗时 ROI 不可计算。仅有单日数据不能证明增长趋势，历史 D0 与独立批次不能证明实际经营效果。
- 本轮未改造医美业务、未升级关键词检索为向量检索，未验证新的真实模型调用、Docker 构建或长期公网托管。
