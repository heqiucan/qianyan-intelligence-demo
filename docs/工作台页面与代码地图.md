# 工作台页面与代码地图

> 页面重构阶段的阅读地图与验收快照。当前开发先看 [项目索引](INDEX.md)，功能定位及验证以 [功能责任矩阵](功能责任矩阵.md)、[测试地图](测试地图.md) 为入口。下方端口、测试数量和“未上传”描述仅代表当时交付，不代表当前运行或 Git 状态。

更新：2026-11-23。对应本次六项改进，说明页面归属、代码入口和验收方法。

## 页面归属

| 一级入口 | 二级工作区 | 详情或编辑 | 地址示例 |
| --- | --- | --- | --- |
| 工作总览 | 指标、待办、当前任务 | 跳入具体业务 | `#/overview` |
| Agent 任务 | 内容任务、需求分析 | 新建、执行、结果审阅、引用 | `#/agent?agent=new`、`#/agent?agent=ID` |
| 商品与知识 | 商品目录、品牌与商品资料、知识库 | SKU、资料编辑、审核 | `#/product?tab=catalog`、`#/product?tab=knowledge` |
| 营销与创意 | 创意素材、活动管理、知识草稿 | 单份创意的编辑、依据、版本 | `#/creative?item=ID` |
| 直播工作台 | 现场控制、场次与货盘、话术管理、素材处理 | 当前场次配置与处理任务 | `#/live?live=ID&pane=session` |
| 广告投放 | 计划列表、模拟场景 | 计划创建、编辑、调整和启动确认 | `#/ads`、`#/ads?scenarios=1` |
| 效果与复盘 | 效果、复盘、活动报告、场次复盘与报告 | 订单来源、单份报告 | `#/analytics?section=orders`、`#/analytics?view=reports&report=ID` |
| 待办与审核 | 活动异常、创意待审、Agent与需求待处理入口 | 对应业务处理 | `#/tasks` |

需求任务固定归属 Agent：`#/agent?tab=demand&view=tasks|library|results|content|attention`。`task=new` 为创建页，`task=ID` 为详情。

旧 `overview?agent=…`、`overview?tab=live`、`creative?tab=live`、`reports`、`review`、`optimize` 及分散的 `tab=demand` 链接由 `frontend/src/navigation.ts` 转换，保留场次、商品、任务等参数。

直播组件在同一场次切设置时保持挂载；素材处理可隐藏画面，但不会因隐藏而销毁音频实例。离开工作台或切场次仍执行原有停止、资源释放和草稿保护。

## 前端阅读顺序

1. `frontend/src/main.tsx`：React 挂载与样式入口。
2. `frontend/src/app/pages.ts`：八项导航与当前位置名称。
3. `frontend/src/App.tsx`：业务页面组合及跨模块交接。
4. `frontend/src/app/AppShell.tsx`：固定导航、移动端菜单、顶栏与内容区。
5. `frontend/src/app/useWorkspaceNavigation.ts`：旧链接、历史前进后退、滚动恢复、未保存内容保护。
6. `frontend/src/app/useWorkspaceData.ts`：全局业务数据读取、筛选、请求忙碌态与错误。
7. 进入下面一个业务目录，追踪一个按钮到接口。
8. `frontend/src/api.ts`：请求、取消、错误转换、重复请求标识。

| 目录或文件 | 职责 |
| --- | --- |
| `app/ScopeFilter.tsx`、`AppDialogs.tsx` | 统计范围与公共弹窗 |
| `features/agent/` | 列表、创建、任务详情与真实事件时间线 |
| `features/demand/` | 需求素材、任务配置、结果确认及选题 |
| `features/creative/` | 素材列表、生成配置、事实编辑、审批与导出 |
| `features/ads/` | 计划弹窗、调整、模拟场景 |
| `features/analytics/` | 计划排名、买家构成、纯数据转换与局部样式 |
| `features/feedback/` | 异常待办、优化复盘、观察、报告列表/表单/详情 |
| `features/live/` | 场次、预览、互动、素材、音频编排 |
| `features/live/speech/` | 话术、播报队列、播放器、文件导入导出 |
| `features/knowledge/` | 资料、检索、引用与知识草稿 |

`Feedback.tsx` 保留兼容入口，只负责选择页面。`CreativeStudio.tsx` 和 `AdsPage.tsx` 保留业务编排，具体视图拆入各自目录。没有增加 npm 包，也没有拆成多个服务。

## 后端阅读顺序

`backend/main.py:create_app` 装配应用与现有业务路由，`backend/core/storage.py` 提供 SQLite 读连接、事务和记录存取。`backend.main.Store/put/get/all_records` 保留兼容导出；种子数据与迁移仍由应用层负责，底层不反向依赖入口。

按业务查看 `backend/agents/`、`backend/speech/`、`backend/demand_*.py`、`backend/knowledge_*.py`、`backend/live_*.py`。本次没有迁移接口、数据库结构或快照含义；`main.py` 和 `v2.py` 的剩余业务拆分需要逐域验证，不应为了目录整齐一次性重写。

## 数据与文案规则

- 图表直接使用当前活动、来源、计划、日期下的接口数据。缺失值与有效的零分开显示。
- 有真实日期明细才绘制时间趋势；固定历史样例不生成假日期。
- 计划条形图点击后沿用计划筛选，订单可查看来源链路；CSV 导出保留完整当前范围。
- 买家构成使用去重人数；分类缺失或人数矛盾时不绘制占比。
- 不用步骤配额计算 Agent 完成百分比。时间线来自实际保存事件。
- 操作页面不再常驻宣传大图、流程口号和重复机制解释。来源、模拟状态、未保存、资料过期和确认条件仍在相关位置保留。
- 当前平台投放与支付仍为模拟。页面产品化不代表新增真实平台、支付或模型能力。

## 验证方法

构建输出使用 `tmp/workspace-v4-dist`，本地预览使用独立 `tmp/workspace-v4-preview/data`。不覆盖原有分享构建或日常数据库。

```powershell
npm.cmd --prefix frontend exec -- tsc --noEmit -p frontend/tsconfig.json
node --test scripts/test_workspace_navigation.cjs
node scripts/test_analytics_visuals.cjs
$env:DEMO_FRONTEND_DIR = Join-Path (Get-Location) 'tmp/workspace-v4-dist'
.venv\Scripts\python.exe scripts/run_e2e.py --scripts browser_workspace_v4.cjs browser_agent_workspace.cjs browser_feedback_workspace.cjs browser_creative_workspace.cjs
```

浏览器验收使用独立 replay 数据库、随机本机端口；脚本拒绝日常服务 8001。已有直播回归继续覆盖真实系统语音、模拟互动、文件预览、测试摄像头、图层、定时、音频、素材和草稿。

设计参考项目固定的 Motion Site Builder `product-ui` 与 CoastSignal（MIT，固定提交见 `vendor/motion-site-builder/UPSTREAM.json`）。采用短交互反馈、语义状态色、减少动画和图表数据表回退。导航、任务状态保护、页面归属和图表计算按当前项目重新实现。在线上游检索本轮未取得有效结果，未据此升级依赖。

Motion MCP 已实际查询参数与参考，应用布局检查通过；后续使用同一项目上游检查脚本批量检查。商品资料中的手动播放视频仍触发“背景视频应自动播放”的误报，不按该评分改成自动播放。
