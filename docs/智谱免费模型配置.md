# 智谱免费模型配置

本版默认接入 **GLM-4-Flash-250414** 文本模型，另允许手动选择 **GLM-4.7-Flash**。2026-11-10 核对智谱官方模型概览及价格表，输入和输出均标为免费。**FlashX 系列是收费型号，不要多填 X。** 价格可能由服务商调整；本程序限制型号和接口，但不能替服务商冻结未来价格。

## 现在准备好了什么

- 生成两组创意：使用活动受众、目标、卖点假设、语气、角度与商品事实，返回标题、正文、行动文案、15 秒视频分镜脚本。
- 单组重新生成：新建素材版本，保留原商品快照与旧计划引用。
- AI 复盘：系统计算数字，模型生成假设、缺失信息和修改建议。
- 采纳素材建议：模型依据已保存的复盘建议生成下一版草稿，继续走事实核对和人工确认。
- 文案与复盘显示各自的生成来源；切换全局模式不会把历史回放标成真实生成。

这是**文本模型**接入，脚本不是视频文件，海报仍由现有模板渲染。广告投放、订单与付款继续是模拟。本次没有接入平台付费搜索、图像或视频模型。

未配置时默认 `replay` 回放。当前本机已导入用户提供的 Key：GLM-4.7-Flash 测试返回 429 / 1305，GLM-4-Flash-250414 连通测试返回 200，因此已显式选择后者。真实业务链路验收结果见同目录《智谱接入验收记录》。没有自动回退。

## 1. 注册并创建免费调用所需的密钥

1. 打开 [智谱开放平台](https://bigmodel.cn)，注册并登录，按平台实际提示完成账号开通。
2. 打开 [API Key 管理](https://bigmodel.cn/usercenter/proj-mgmt/apikeys)，创建**标准 API Key**。无需购买 Coding Plan。
3. 核对 [官方模型概览](https://docs.bigmodel.cn/cn/guide/start/model-overview) 和 [官方定价](https://docs.bigmodel.cn/cn/guide/start/pricing)：`GLM-4-Flash-250414` 输入、输出应仍为免费。如果页面要求购买或价格已变，先停止配置，核实账号和所选型号。
4. 复制密钥，在下一步本机窗口输入。不要把密钥发到聊天里、放进网页代码或写进截图。

## 2. 双击本机配置文件

在项目根目录双击 **configure-zhipu.cmd**。

粘贴密钥后按回车；输入时不显示字符是正常现象。直接按回车会取消，旧配置不变。配置向导只写本机 `.env`，不会立即调用模型，也不会改活动、素材或订单。

向导固定写入：

```dotenv
MODEL_PROVIDER=zhipu-free
MODEL_BASE_URL=https://open.bigmodel.cn/api/paas/v4
MODEL_NAME=glm-4-flash-250414
MODEL_API_KEY=在本机填写
```

程序只允许上述两款免费文本模型和智谱官方端点；失败时只显示错误，不自动换型号或降级成回放。`.env` 已在 `.gitignore` 中，不过它仍是本机明文配置，请不要分享此文件。项目位于 OneDrive 文件夹，`.gitignore` 不会阻止 OneDrive 同步。

## 3. 检测连接，再重新启动 Demo

双击 **check-zhipu.cmd**。它读取本机 `.env`，显式发送一个很短的 JSON 连通测试，不发送商品或订单。Demo 重启后也可以在网页 **演示设置 → 测试免费模型连接** 中验证当前服务实际使用的配置。

- 显示“连接成功”：账号与免费模型接口可用，接下来重启 Demo。
- 显示“尚未配置”：先完成步骤 2。
- 显示密钥或权限问题：核对标准 API Key、账号开通状态，勿购买 Coding Plan 解决此问题。
- 显示限流或超时：稍后手动重试。免费模型也有服务容量限制，实际额度以账号控制台为准。
- 显示型号不可用：先查官方模型页面，不要改成 FlashX 或其他收费型号。

关闭原来启动 Demo 的终端窗口，或在该窗口按 `Ctrl+C` 停止服务，再双击原来的 **start-demo.cmd**（已有桌面启动入口也可继续用）。如果启动器提示“Demo 已经运行”，它只是打开现有服务，**不会重载新配置**。

`scripts/start_demo.py` 才会读取 `.env`。直接运行 uvicorn / Docker 时需要显式提供相同环境变量。已有进程环境里的 `MODEL_*` 优先于 `.env`；如有旧配置，应先清除旧环境变量。

## 4. 在网页里验收

1. 打开原来的八入口后台 → **演示设置**，AI 模式应显示“智谱 · GLM-4-Flash-250414”。首次显示“已配置，等待首次调用验证”是正常状态。
2. **商品与品牌**：填写商品可证实的资料；已有活动保留原资料快照，新资料请用于新活动。
3. **营销与创意**：设置语气、角度，点击“生成两组创意”；生成期间显示真实等待状态，返回后保存两份草稿。
4. 查看“当前保存版本来源”：应显示 `智谱生成 · glm-4-flash-250414`。旧素材继续标为“演示回放”。编辑保存的新版本另标“人工修订”。
5. 做一次事实核对、人工确认，按原流程创建模拟计划。模型成功不等于商品事实或广告合规检查通过。
6. **AI 优化复盘**：选定数据范围，生成复盘；数字由程序计算，模型不决定 ROI 和订单数。采纳素材建议后创建新草稿，不自动投放。
7. 再看 **演示设置**：“本次服务运行已成功调用”表示当前进程成功收到并校验过模型结果或网页连接测试。单独运行 `check-zhipu.cmd` 不会改变正在运行的网页状态。

复盘发送汇总指标及分组数据，不发送买家 ID 和逐笔订单。生成时不持有 SQLite 写锁；重复请求复用已保存结果，正在进行的重复生成会提示等待。限流、超时或格式错误不覆盖原内容。

## 需要回到离线演示时

在项目目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/configure_zhipu.py --replay
```

然后重新启动 Demo。旧数据、智谱生成的草稿和来源记录均保留；只改变下一次生成的方式。
