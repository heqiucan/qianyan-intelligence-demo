## 报告采用方式

- 采用可验证的方向：FFmpeg 本地处理，素材来源记录，场次隔离，音频与画面独立控制，生成内容人工确认，模型提供者复用。
- 不采纳为程序常量：首包80/97/150ms、准确率98%、实时169.6倍、统一最低12GB显存、单通道上限、所有业务统一税率、固定处罚次数和报白时限。这些需要相同测试条件或适用主体/官方条文。
- 报告内部有相互冲突的概括：CosyVoice 协议先称Apache2.0、后又归为MIT；先称第三方直推全面禁止、后又列“官方仅开放RTMP直推”；RTF与速度倍数交替使用。不能按该文本直接宣布商业授权或平台接入可行。
- 本次只调用本机已有FFmpeg，不把二进制加入代码库；不将其本机GPL构建说成统一LGPL授权。
- 没有开通支付、收费、克隆他人声音、申请抖音权限、变更系统安全配置或加入新的云端账号。

## 本次落地

| 功能 | 落地形态 | 边界 |
| --- | --- | --- |
| 定时插播与报时 | 规则内定时触发、顺序/随机、服务器时间变量与明确时区、客户端显式启停 | 本页可见且模拟运行；后台、断网、刷新停止，不补发，不向真实公屏发送 |
| 文字场控 | 定时文字写入本地处理结果 | 平台发送未接入 |
| 图层 | 两路本地图片/视频、可见度、缩放、位置、翻转、不透明度 | 浏览器预览，无合成输出、网页源或平台去重承诺 |
| 画面滤镜 | 亮度、对比度、饱和度、灰度、暖色与重置 | 不是商业美颜SDK，无音频变调 |
| 主副音频/环境音 | 五个独立通道、文件列表、间隔、循环、音量、启停 | 本地浏览器，无虚拟声卡或混音文件导出 |
| 音量闪避 | 实际TTS或副音频播放时背景音量降低、暂停后恢复 | 浏览器当前通道范围，不控制其他软件 |
| 麦克风 | 显式授权、最多60秒录音、回放/下载 | 不是实时麦克风插话或监听 |
| 音频批量转换 | 1–5个本地音视频、24kHz单声道PCM WAV、来源哈希、ZIP | 单批100MB、单文件15分钟；上传到项目服务器处理 |
| 音频切片 | 静音阈值/持续时间、最短最长片长、切片下载 | FFmpeg静音切片，不是语义或关键词过滤 |
| 字幕 | 人工时间轴校验、SRT保存与下载 | 自动ASR能力单独以实际模型验证结果为准 |
| 话术新写/改写 | 当前模型适配器+商品依据+旧稿版本，编辑确认后导入新组 | replay仅事实模板；未实际调用云模型，不能声称AI改写效果已验收 |

## 需要另行接入的能力

- 抖音真实弹幕/礼物/人数、商品卡、自动补链接、真实公屏与推流：需要相应官方能力和账号权限，不能用报告里的非官方工具推断已经授权。
- 新本地TTS/音色克隆：需要选定模型及权重、硬件实测、参考音频与使用范围；本次继续使用系统音色。
- 云端多模型和收费：需要用户选择服务、预算与账户，当前复用已有配置，不自动选择付费服务。
- 卡密充值与真实扣费：缺业务计价和支付渠道，没有用演示余额假装真实算力。
- 整场AI替你播、自动知识库客服、完整内容显/隐式标识：仍需各自业务规则与验证。本地规则和文件元信息不等于完成全部合规要求。

## 资源与验收

新前端构建目录为 tmp/report-dist，独立本地服务8044。已有分享链接继续使用旧构建，不在开发时推送不完整页面。

分别测试设备/文件资源释放、拒绝授权、后台暂停、队列多页互斥、规则版本、货盘版本、失败重试、上传配额、取消与重启恢复，再跑完整浏览器回归。自动化麦克风/摄像头使用测试设备；没有自动开启用户实体设备。

本回合同样使用项目固定 Motion Site Builder product-ui 参数与 CoastSignal 参考。未升级框架依赖。媒体任务调用本机工具，图层和音频编排使用浏览器原生能力，定时/审核/版本保护针对当前项目实现。
