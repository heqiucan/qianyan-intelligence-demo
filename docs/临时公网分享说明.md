# Qianyan Intelligence 临时公网分享

2026-11-11 按用户要求生成可发给他人的 HTTPS 网址。使用 Cloudflare Quick Tunnel，不注册账号，不购买域名，不安装系统服务。

## 当前会话

2026-11-14 按用户要求启用免访问码分享。启动命令为 `.\.venv\Scripts\python.exe scripts/share_demo.py serve --no-access-code`；省略此参数仍会生成访问码，仅影响独立分享进程。

网址、访问模式及可选访问码保存在 `tmp/share-runtime/session.json`，转发文字在同目录 `分享信息.txt`。这些文件已经由 `.gitignore` 排除，不作为仓库公开内容。

官网地址以 `/website.html` 结尾，可以直接访问。官网“进入工作台”及八个模块入口都使用相同公网域名；当前免访问码会话可以直接进入工作台。

电脑需要保持开机、联网并且不睡眠。公网连接由后台进程维持。双击根目录 `stop-share.cmd` 可停止本次公网分享，不影响原本地 Demo 启动方式。停止进程或关机后链接失效；重新建立 Quick Tunnel 会生成不同的网址，暂未配置固定域名和长期服务器托管。

## 分享范围

- 分享进程单独启动 FastAPI 服务，绑定本机回环地址，由 Cloudflare 提供临时 HTTPS 转发。
- 使用 `tmp/share-runtime/demo-data` 中的独立示例数据，不复制原工作台的数据库或上传素材。
- 分享进程不加载 `.env`，明确设置 `MODEL_PROVIDER=replay` 并清空模型密钥。页面显示“演示回放”；不会调用本机智谱模型。
- 官网与交互讲解公开可看。免访问码模式下业务 API 也无需访问码；默认带访问码模式下，未提供访问码返回 401。
- 工作台是共用的演示空间，免访问码模式下，持有链接的人可以操作其中的数据；不是多租户隔离或生产级账户系统。
- 页面、粒子、流程等资源从当前前端生产构建提供，未上传项目源码或密钥。

## 实现与来源

- `scripts/share_demo.py`：本次分享进程管理、独立环境、访问码、状态文件以及停止操作。
- `tmp/share-runtime/cloudflared.exe`：官方 `cloudflare/cloudflared` **2026.10.7** Windows amd64 发布文件；执行前已核对官方发布的 SHA256。版本、下载 URL、摘要保存在 `cloudflared-source.json`。
- `stop-share.cmd`：请求管理进程停止自己启动的服务和隧道，不扫描或终止其他服务。
- 使用官方 Quick Tunnel 的现成 HTTPS 转发；本项目自行实现独立演示数据和启动管理，没有修改 Cloudflare 工具源码。

上游：

- [Cloudflare Quick Tunnels 官方说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
- [cloudflare/cloudflared 2026.10.7 官方发布](https://github.com/cloudflare/cloudflared/releases/tag/2026.10.7)

Quick Tunnel 用于临时测试演示，没有持续可用保证，网址随会话变化。长期稳定访问需要固定隧道或部署至持续运行的服务器。
